# Privacy Policy — Chess for Kids

Same text as the in-app page (parent area → Privacy; linked from the first-run parent password
screen). Source of truth for wording: `common:parent.privacy.*` (`packages/content/locales/en/common.yaml`).

Chess for Kids keeps everything on this device. Here's exactly what that means.

## What we keep

A nickname, an avatar picture, and lesson progress for each child — stored only on this device,
never sent anywhere.

## No accounts, no tracking

No sign-up, no analytics, no ads, no third-party services. The app never phones home.

## Network use

The only network access is checking for app updates. Updates are static files delivered from
GitHub Pages. "Send to other device" hands the file to whichever app or device the parent picks —
the app itself still sends nothing.

## Parent control

Export or delete any child's data any time, from Backup and from that child's Settings in the
parent area.

## Questions?

Open an issue on the project's GitHub repository: https://github.com/enricoag1982/learningChess/issues
