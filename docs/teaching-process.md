# Teaching Process — Chess for Kids (age 8, beginner)

## 1. Principles

| # | Principle | Source |
|---|---|---|
| 1 | One concept at a time, many exercises per concept, next topic only after mastery (~80% correct) | Steps Method |
| 2 | Reduced positions first (few pieces, one clear goal); full game only after all rules are known | Mini-game coaching practice |
| 3 | Sequence: moves → capture/defend → check → mate. Mate postponed | Steps Method |
| 4 | Simple pieces first: Rook → Bishop → Queen (= R+B) → King → Knight → Pawn (most exceptions) | Lichess, ChessKid |
| 5 | Story/character per piece: rule anchored to a story | Story Time Chess, Magnus' Kingdom |
| 6 | Minimal text; voice + visuals; no notation | Stepping Stones |
| 7 | Sessions 10–15 min; frequent > long | Educational game research |
| 8 | Spaced review: old topics revisited every session | Spaced repetition research |
| 9 | Positive feedback; error = hint + retry, no penalty | Educational game research |
| 10 | Safety habit from early on ("Is my piece safe?"); hanging pieces = #1 beginner error | ChessKid, Premier Chess |

## 2. Reference works

| Work | Type | Take-away |
|---|---|---|
| Steps Method (NL, 1987) | Coaching method + workbooks | Proven topic sequence (Step 1 = 15 lessons); mastery via exercise volume; mate postponed |
| Stepping Stones | Steps Method for ages 6–9 | Big diagrams, almost no text, easy exercises, no notation |
| Lichess Learn | Free web | Per piece: collect stars in minimum moves; 1–3 stars per stage |
| ChessKid (Chess.com) | Kids app, 5–12 | Levels named after pieces (Pawn → King); lessons + puzzles + bots; safe environment |
| Story Time Chess | Board game + book, 3+ | Story per piece, 4 mini-games per piece |
| Magnus' Kingdom of Chess (DragonBox) | Adventure app, 6+ | Map, gradual piece unlock. Weakness: check/mate rushed → give it a dedicated phase |
| Coaching mini-games | Club practice | Pawn Wars, Win the Queen, Capture the Flag, knight games: one skill per game |

## 3. Learning loop

### 3.1 Per concept (5–8 min)
1. **Story** (30 s): character + rule.
2. **Demo**: legal moves highlighted.
3. **Guided try**: 2–3 easy tasks, hints on.
4. **Exercises**: 5–10 tasks, rising difficulty, 1–3 stars.
5. **Mini-game** vs computer: skill applied in a game.
6. **Review**: 2–3 tasks of the concept in later sessions.

### 3.2 Per session (~12–15 min)
Warm-up review (2 min) → 1 new concept (5–8 min) → 1 mini-game (5 min).

### 3.3 Feedback and mastery
- Wrong move: undo + short spoken explanation.
- Hint ladder: highlight piece → highlight target squares → show move.
- 3 stars = no hint, no error.
- 2 failures on a concept → easier variant, concept added to review.
- Mastery = ≥80% of max stars on the concept; required to move on.

## 4. Curriculum

| Phase | Content | Mini-games |
|---|---|---|
| 1. Board | Squares, light/dark; rows, columns, diagonals; setup (light square bottom-right, queen on her colour) | Square Hunt, Setup Race |
| 2. Pieces | R, B, Q, K, N, P incl. capture. Pawn: double first step, diagonal capture, promotion | Star Collector, Hungry Piece, Knight Maze, Pawn Wars |
| 3. Attack & defence | Attack, capture, defend, hanging piece, values (P1 N3 B3 R5 Q9), good/bad exchange | Safe or Not?, Queen vs Pawns, Army Battle, Win the Queen |
| 4. Check & mate | Check; 3 escapes (move / block / capture); checkmate; stalemate; mate in 1 | Escape the Check, Mate in 1, first full game vs computer |
| 5. Full rules | Castling, en passant, draws (stalemate, repetition, insufficient material; 50-move rule mentioned only) | Full game vs computer |
| 6. First games | Opening rules: centre, develop knights/bishops, castle early, queen not too early. Pre-move check: checks, captures, threats | Full game vs computer |
| 7. Winning | K+Q vs K, K+2R vs K (ladder), K+R vs K. Tactics: fork, pin, skewer, discovered attack | Lonely King, tactic puzzles |

**Milestones**
- After phase 4: plays a full legal game with help.
- After phase 6: plays independently.
- After phase 7: converts won positions.

## 5. Mini-games

| Mini-game | Setup | Goal | Skill |
|---|---|---|---|
| Square Hunt | Empty board | Tap all squares of a row / column / diagonal | Board geometry |
| Setup Race | Pieces off board | Place all pieces in start position | Setup |
| Star Collector | 1 piece + stars | Collect all stars in min moves | Piece movement |
| Hungry Piece | 1 piece vs static enemies | Capture all | Movement + capture |
| Knight Maze | Knight + blocked squares | Reach target | Knight jump |
| Pawn Wars | 8 pawns each | First promotion wins | Pawns, blocking, promotion |
| Queen vs Pawns | Q vs 8 pawns | Q captures all / a pawn promotes | Long-range pieces, defence |
| Safe or Not? | Position + highlighted piece | Answer yes / no | Hanging pieces |
| Army Battle | Pawns + 1 piece type each, no kings | Capture all | Attack, defence, exchange |
| Win the Queen | Full set | First to capture the queen wins | Piece safety |
| Escape the Check | King in check | Find all escapes | 3 ways out of check |
| Mate in 1 | Set positions | Deliver mate | Mate patterns |
| Lonely King | K+Q or K+2R vs K | Mate within N moves | Basic mates |
| Full game | Normal, weak computer | Win | Everything |

## 6. Decisions

| Topic | Options | Chosen |
|---|---|---|
| Piece order | Simple-first (Lichess, ChessKid) / pawns-first (Pawn Wars first) | Simple-first |
| Mate timing | Postponed (Steps) / early (Lichess) | Postponed, dedicated phase 4 |
