  `.map(level => level.name)` from it instead of re-typing the list.
- `start.ts`'s `STANDARD_START_BOARD` (the C5 `isStandardStart` seam, whose own comment already
  notes it replaced 3 separate start-FEN copies) is now also the source `chess/facts/rewards.ts`'s
  `STANDARD_START_FEN` derives from (`${STANDARD_START_BOARD} w KQkq - 0 1`) instead of repeating
  the board layout as a second literal.

Evaluated, not applied:
- **`export *` barrels**: checked whether `chess.ts`'s curated re-export blocks from
  `domain/chess/index.ts` and `domain/exercise/index.ts` could become `export * from` /
  `export type * from`. Neither source module's full export set matches what `chess.ts` currently
  re-exports (e.g. `domain/chess/index.ts` also exports `Markers`, `isSquare`, `toDiagram`,
